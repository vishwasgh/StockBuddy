# 📈 StockBuddy (Frontend)

**StockBuddy** is a stock analysis and prediction platform built with modern web technologies.  
This repository contains only the **frontend** of the project, developed using **Next.js** and **Tailwind CSS**.

> ⚠️ This project is currently in development and runs locally. No live demo is available yet.

---

## 🚀 Features

- 📊 Technical Analysis (Support/Resistance, Trend Detection, Chart Patterns)
- 📰 News & Sentiment Analysis
- 🤖 Price Prediction using Machine Learning models
- 🎯 Strategy-based Trading (e.g., RSI, Bollinger Bands)
- 📉 TradingView Widget Integration
- 🧠 Ownership Network Visualization

---
## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Runtime**: Node.js (Localhost only)
- **Extras**: TradingView Widgets, Chart.js

## 🔧 Getting Started

To run the project locally on your machine:

```bash
git clone https://github.com/vishwasgh/StockBuddy.git
cd StockBuddy

npm install
npm run dev
````

Then open your browser at [http://localhost:3000](http://localhost:3000)
